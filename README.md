### AI Sales OS Dashboard

**Fullstack MVP for sales team analytics and AI-assisted management.**

The product is designed for sales leaders who need to monitor team performance, analyze funnel problems, review call quality, work with knowledge bases and generate AI-powered reports.

What it includes:

### Sales Analytics & AI Coaching System

**Internal AI-assisted system for sales call analysis, quality control and manager coaching.**

The system processes call recordings, transcribes them with local Whisper, analyzes communication quality using LLM tools and generates structured reports for managers and team leads.

What it helped with:

- Faster call review
- Detection of weak points in sales communication
- Analysis of rejection reasons
- Manager coaching recommendations
- Team performance review
- Sales funnel problem detection

**Result:** reduced the initial review of a manager's weekly calls from **1–2 days of manual listening** to **10–20 minutes**.

**Stack:** Telegram Bot, local Whisper, LLM tools, Obsidian, Markdown, Google Sheets, CRM exports.

---

### Second Brain / RAG Knowledge Base

**Local knowledge base with Telegram input, Markdown storage and RAG-style search.**

The system collects text, files and voice messages through Telegram, processes them with LLM tools, creates summaries and saves structured notes into a Markdown-based knowledge base.

What it includes:

- Telegram input for text, files and voice messages
- Local Whisper transcription
- LLM-based summarization
- Markdown knowledge base
- Obsidian-style structure
- Basic RAG search logic
- Web UI foundation

**Stack:** Python, Telegram Bot, OpenRouter, Markdown, local Whisper, web UI.
